# leonfighter1.github.io

The root of https://leonfighter1.github.io/. It only exists to make the
drawing app's address work however it is typed:

- `index.html`: the front page opens the app.
- `404.html`: GitHub Pages matches project paths letter for letter, so
  `/jingyaopaint/` would not find `/JingyaoPaint/`. Every path GitHub can't
  find lands on this page, which sends any spelling of `/jingyaopaint` or
  `/joypainting` (any capitals) to https://leonfighter1.github.io/JingyaoPaint/.

The app itself lives in https://github.com/leonfighter1/JingyaoPaint.
